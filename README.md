# gradient-boosted-trees-from-scratch-adaboost-logitboost-and-xgboost
Build the boosting chapter of Murphy's Probabilistic Machine Learning in NumPy, from one tree that sees only gradients and Hessians. Feed it squared-error statistics and it matches scikit-learn's CART to rounding. Feed it log-loss statistics and your booster matches the real xgboost library margin for margin.
